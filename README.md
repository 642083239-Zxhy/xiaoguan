# 雷龙 L1 · AI 鼠标销售智能体

面向电脑外设销售场景的中文 AI 导购项目。系统围绕雷龙 L1 系列鼠标，实现用户意图识别、选购条件追问、商品推荐与对比、规则报价、知识库问答、客户购买意向分析，以及本地会话和授权长期记忆管理。

> 当前版本为可本地运行的 MVP。已实现需求中的 1、2、3、4、5、8；文档本地向量化、真实人工客服转接和语音回复（需求 6、7、9）暂不在本期范围。

## 核心功能

- 识别 15 类销售意图，并生成主意图、次意图、置信度、实体、情绪、风险标记和下一步动作等结构化结果。
- 根据使用场景、预算和设备系统进行硬过滤与商品排序。
- 支持 L1 基础版与 L1 Pro 的参数查询、对比、兼容性说明和无图片商品卡片。
- 通过确定性规则计算公开价、活动价、数量合计、价格底线和折扣权限。
- 可选接入阿里云百炼知识库应用；网页会把会话、预算、推荐、报价和授权记忆通过 `biz_params` 传给模型。
- 使用 SQLite 保存会话消息、结构化摘要、事实、推荐结果、报价版本和隐私审计记录。
- 匿名会话默认保留 7 天；长期记忆必须经过用户授权，支持撤回和删除。
- 后台支持 SKU、FAQ、话术维护，以及会话转化率统计。
- API Key 只保存在浏览器 `sessionStorage`，不会写入源码和 Git。

## 环境要求

- Node.js 20 或更高版本
- npm
- Python 3.10 或更高版本
- Windows 10/11（`run.cmd` 快捷脚本适用）或 macOS

Python 数据服务只使用标准库，无需安装第三方包。

## 快速开始

### 1. 克隆并安装依赖

```powershell
git clone https://github.com/642083239-Zxhy/xiaoguan.git
cd xiaoguan
npm ci
```

### 2. 启动本地数据库服务

打开一个 PowerShell 窗口：

```powershell
cd XGshujuku
.\run.cmd serve
```

服务默认运行在 `http://127.0.0.1:8765`，数据库文件会自动创建在 `XGshujuku/data/xg.db`。

### 3. 启动网页

打开另一个 PowerShell 窗口，在项目根目录运行：

```powershell
npm run dev
```

浏览器访问 `http://127.0.0.1:5173/`（Vite 默认端口，若被占用会自动递增）。

未配置大模型时，推荐、参数、报价和意图分析仍可由本地规则引擎运行。

## 配置阿里云百炼知识库

1. 在百炼控制台创建并发布知识库应用。
2. 打开网页，点击顶部“AI与知识库配置”。
3. 选择“百炼知识库应用”。
4. 填写应用 `APP_ID` 和 API Key。
5. 点击连接测试，成功后保存。

网页通过 Vite 本地代理向百炼发起请求，密钥不会进入前端构建文件。请勿把真实密钥写入源码、README、截图或提交记录；如果密钥曾公开，请立即在控制台轮换。

数据库测试覆盖匿名会话生命周期、消息顺序、上下文优先级、长期记忆授权、敏感信息拦截、授权撤回、推荐和报价持久化、结构化摘要与百炼分析上下文。

## 数据与隐私

- `XGshujuku/data/`、`*.db`、环境文件、依赖和构建目录均已加入 `.gitignore`。
- 不得把真实客户姓名、联系方式、身份证、银行卡、密码或聊天原文提交到仓库。
- 长期记忆只有在用户授权后才允许写入，并支持撤回授权和清理。
- 价格、库存、折扣与兼容性必须来源于结构化数据或确定性规则，不能由模型猜测。
- 当前购买链接和人工客服尚未接入真实业务系统，页面不会生成虚假地址或联系方式。

## 当前限制

- 商品库目前仅包含 L1 基础版和 L1 Pro 两个示例 SKU。
- 实时库存、物流、商城订单和人工客服系统尚未接入。
- 百炼回答质量取决于已发布应用、知识库文档和提示词配置。
- SQLite 适合本地演示和单机 MVP；生产环境建议迁移到 PostgreSQL，并补充身份认证、访问控制、加密、备份和监控。
