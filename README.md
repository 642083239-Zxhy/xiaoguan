# 雷龙 L1 · AI 鼠标销售智能体

面向电脑外设销售场景的中文 AI 导购项目。系统围绕雷龙 L1 系列鼠标，实现用户意图识别、选购条件追问、商品推荐与对比、规则报价、知识库问答、客户购买意向分析，以及本地会话和授权长期记忆管理。

> 当前版本为可本地运行的 MVP。已实现需求中的 1、2、3、4、5、8；文档本地向量化、真实人工客服转接和语音回复（需求 6、7、9）暂不在本期范围。

## 核心功能

- 识别 15 类销售意图，并生成主意图、次意图、置信度、实体、情绪、风险标记和下一步动作等结构化结果。
- 收集使用场景、预算和设备系统等条件，并作为上下文发送给百炼知识库应用。
- 支持把知识库返回的推荐、参数、价格、对比和兼容性 JSON 渲染成对应界面与无图片商品卡片。
- 业务回答只调用已发布的阿里云百炼知识库应用；商品、价格、推荐、限制边界和话术均以知识库及应用提示词为准。
- 网页会把会话、预算、推荐、报价和授权记忆通过 `biz_params` 传给百炼应用，但不会传入本地商品目录。
- 使用 SQLite 保存会话消息、结构化摘要、事实、推荐结果、报价版本和隐私审计记录。
- 匿名会话默认保留 7 天；长期记忆必须经过用户授权，支持撤回和删除。
- 后台提供知识库维护指引和本地会话转化率统计；SKU、FAQ 与销售话术统一在百炼控制台维护。
- API Key 只保存在浏览器 `sessionStorage`，不会写入源码和 Git。
- 首页使用 OGL WebGL 背景效果；商品引导卡支持鼠标互动，并兼容系统“减少动态效果”设置。

## 技术栈

| 模块 | 技术 |
| --- | --- |
| 前端 | React 19、Vite 8、Tailwind CSS、Lucide React、OGL |
| 业务回答 | 阿里云百炼知识库应用（固定 JSON 响应） |
| 知识库 | 阿里云百炼应用 API（可选） |
| 本地数据服务 | Python 3.10+ 标准库 HTTP 服务 |
| 数据库 | SQLite（WAL 模式） |
| 测试 | Node.js Test Runner、Python unittest、Oxlint |

## 环境要求

- Node.js 20 或更高版本
- pnpm 9 或更高版本
- Python 3.10 或更高版本
- Windows 10/11（`run.cmd` 快捷脚本适用）

Python 数据服务只使用标准库，无需安装第三方包。

## 快速开始

### 1. 克隆并安装依赖

```powershell
git clone https://github.com/642083239-Zxhy/xiaoguan.git
cd xiaoguan
pnpm install --frozen-lockfile
```

### 2. 启动本地数据库服务

打开一个 PowerShell 窗口：

```powershell
cd XGshujuku
.\run.cmd serve
```

服务默认运行在 `http://127.0.0.1:8765`，数据库文件会自动创建在 `XGshujuku/data/xg.db`。

### 3. 启动网页

打开另一个 PowerShell 窗口，在项目根目录运行：

```powershell
pnpm run dev
```

浏览器访问 `http://127.0.0.1:3000/`。

未配置百炼应用 ID 和 API Key 时，商品、参数、价格、推荐和对比问题统一返回“知识库未连接，暂时无法提供商品信息”。

## 配置阿里云百炼知识库

1. 在百炼控制台创建并发布知识库应用。
2. 打开网页，点击顶部“AI与知识库配置”。
3. 选择“百炼知识库应用”。
4. 填写应用 `APP_ID` 和 API Key。
5. 点击连接测试，成功后保存。

网页通过 Vite 本地代理向百炼发起请求，密钥不会进入前端构建文件。请勿把真实密钥写入源码、README、截图或提交记录；如果密钥曾公开，请立即在控制台轮换。

数据库测试覆盖匿名会话生命周期、消息顺序、上下文优先级、长期记忆授权、敏感信息拦截、授权撤回、推荐和报价持久化、结构化摘要与百炼分析上下文。

## 数据与隐私

- `XGshujuku/data/`、`*.db`、环境文件、依赖和构建目录均已加入 `.gitignore`。
- 不得把真实客户姓名、联系方式、身份证、银行卡、密码或聊天原文提交到仓库。
- 长期记忆只有在用户授权后才允许写入，并支持撤回授权和清理。
- 商品、价格、库存、折扣与兼容性必须来自百炼知识库应用返回的结构化数据，不能由本地代码或模型常识补写。
- 当前购买链接和人工客服尚未接入真实业务系统，页面不会生成虚假地址或联系方式。

## 当前限制

- 本地不保存商品库、FAQ 或销售话术；未连接百炼知识库 API 时无法提供商品信息。
- 实时库存、物流、商城订单和人工客服系统尚未接入。
- 百炼回答质量取决于已发布应用、知识库文档和提示词配置。
- SQLite 适合本地演示和单机 MVP；生产环境建议迁移到 PostgreSQL，并补充身份认证、访问控制、加密、备份和监控。

## 主要验收结果

- 知识库未连接拦截、固定 JSON 契约和多种百炼商品数组格式兼容通过自动化验证。
- 商品卡字段只映射知识库明确返回的参数，缺失字段不会使用本地数据补齐。
- 会话、事实、推荐、摘要、报价和授权记忆可写入并回读。
- SQLite 完整性检查正常、外键违规为 0。
- 前端可完成生产构建；知识库响应必须符合 `xg-knowledge-response-v1` JSON 契约。
